🔐 Caesar Cipher Encryption Tool
This project is a simple implementation of the Caesar Cipher algorithm, a basic encryption technique used in cybersecurity. The tool allows users to encrypt and decrypt text messages by shifting characters based on a user-defined key.

🚀 Features
Encrypt text using a shift value
Decrypt encrypted text using the same shift
Supports both uppercase and lowercase letters
Keeps spaces and special characters unchanged

🧠 How It Works
The Caesar Cipher works by shifting each letter in the message by a fixed number of positions in the alphabet. For example, with a shift value of 3, 'A' becomes 'D', and 'Z' wraps around to 'C'.

💻 Technologies Used
Python

📌 Usage
Run the program
Enter your message
Choose encryption or decryption
Provide a shift value
View the result

🔐 Learning Outcome
This project demonstrates basic concepts of encryption, substitution techniques, and key-based security in cybersecurity.
